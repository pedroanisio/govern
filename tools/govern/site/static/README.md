# site/static

Part of the [govern website](../README.md), in [super-tools](../../../../README.md).

Copied as is to `dist/static/` (this file and dotfiles are skipped). `site.css` is the theme: palette tokens on `:root`, dark mode under `prefers-color-scheme: dark`, system fonts. Brand images go in `brand/` and are referenced as `/static/brand/<name>`.
