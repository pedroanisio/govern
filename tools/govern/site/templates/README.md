# site/templates

Part of the [govern website](../README.md), in [super-tools](../../../../README.md).

`layout.ts` is the one page layout: skip link, header with the wordmark and top navigation, a side list for the page's section, title, description, content, and a footer with the govern version and commit. Brand images (wordmark, favicon, social card, home hero) are used only when they exist in `static/brand/`. The only scripts are two small inline ones for the mobile menu; the site reads without them.
