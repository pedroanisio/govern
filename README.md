# govern

Run lanes of agent work (videos, software, ops, any process) through checked stages, with few tokens.

- Launcher: [bin/govern](bin/govern) (`bin/govern --help` prints the manual page; needs Node 24 or later for everything else)
- Code, tests and documentation: [tools/govern/](tools/govern/), starting at [tools/govern/README.md](tools/govern/README.md)
- Releases: tags named `govern-vX.Y.Z`

Govern was developed inside the `super-tools` repository and moved here with its history, which is why it lives under `tools/govern/`.
